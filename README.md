# ⚡ Projet Voltaire Assistant

**Une extension navigateur pour améliorer l'expérience d'utilisation de Projet Voltaire.**

Projet Voltaire Assistant est un projet personnel d'extension navigateur développé en JavaScript. Il propose une interface personnalisable et différents outils d'interaction avec le site Projet Voltaire.

## ✨ Fonctionnalités

- Interface personnalisable.
- Réglage des délais d'interaction.
- Paramètres dédiés aux exercices de type glisser-déposer.
- Inspecteur d'éléments pour le débogage.
- Statistiques de session.
- Paramètres sauvegardés localement.

## 🛠️ Technologies utilisées

- JavaScript
- HTML
- CSS
- Chrome Extensions API

## 📦 Installation

1. Télécharge ou clone ce dépôt.
2. Ouvre `chrome://extensions/` dans ton navigateur.
3. Active le **Mode développeur**.
4. Clique sur **Charger l'extension non empaquetée**.
5. Sélectionne le dossier du projet.
