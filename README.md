# 🚀 Voltaire AI (Beta)

Assistant automatisé pour faciliter l'entraînement sur le Projet Voltaire.

---

## 📥 Installation (Chrome, Opera, Brave, Edge...)

L'extension est distribuée sous forme de fichier `.crx` prêt à l'emploi. Suivez ces étapes pour l'installer :

### 1. Télécharger l'archive
1. Rendez-vous dans la section **[Releases](../../releases)** à droite de cette page.
2. Téléchargez le fichier **`.zip`** de la dernière version disponible.
3. Faites un clic droit sur le fichier téléchargé et sélectionnez **Extraire tout...** (dézippez le dossier). Vous y trouverez un fichier se terminant par **`.crx`**.

### 2. Installer l'extension dans le navigateur
1. Ouvrez votre navigateur (Google Chrome, Opera, Brave, Edge...).
2. Dans la barre d'adresse en haut, tapez **`chrome://extensions/`** et appuyez sur Entrée.
3. Activez le **Mode développeur** grâce à l'interrupteur situé tout en haut à **droite**.
4. Ouvrez votre explorateur de fichiers, attrapez le fichier **`.crx`** et **glissez-déposez-le** directement au milieu de la page des extensions de votre navigateur.
5. Une fenêtre apparaît en haut : cliquez sur **Ajouter l'extension** pour valider.

> ⚠️ **Important :** N'utilisez pas le bouton *"Charger l'extension non empaquetée"* avec le fichier `.crx`, cela ne fonctionnera pas. Le glisser-déposer est obligatoire.

---

## 🛠️ Comment l'utiliser ?

1. Cliquez sur l'icône **Extensions** (la pièce de puzzle 🧩) en haut à droite de votre navigateur et épinglez **Voltaire AI (Beta)** pour la garder accessible.
2. Allez sur le site du **Projet Voltaire** et lancez une session d'entraînement.
3. Ouvrez le menu de l'extension, réglez la vitesse ou le taux d'erreur souhaité, puis cliquez sur **Activer**.

---

## ❓ En cas de problème
* **L'extension ne réagit pas :** Actualisez la page du Projet Voltaire (`F5`) après avoir activé l'extension.
* **Erreur lors du glisser-déposer :** Vérifiez bien que le **Mode développeur** est activé avant de lâcher le fichier `.crx` sur la page.
